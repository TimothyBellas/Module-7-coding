Ollama runs language models locally and exposes an HTTP API. The default local address is http://127.0.0.1:11434. The /api/tags endpoint lists installed models, /api/embed generates text embeddings, and /api/chat generates a response to chat messages.

A generation model and an embedding model serve different roles in this project. llama3.2 generates answers and nomic-embed-text embeds documents and questions. Ollama must be running and the required model must be installed before the application can use it. A nonstreaming chat request sets stream to false.
